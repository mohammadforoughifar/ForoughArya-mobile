# راهنمای استقرار و نصب وب‌اپلیکیشن آیفون فروغ آریا (iOS Safari PWA — نسخهٔ `v1.70.0`)

این بسته نسخهٔ **جامع، خودکفا و قابل‌اجرای آیفون (iPhone / iPad PWA)** از اپلیکیشن موبایل فروغ آریا است که **۱۰۰٪ امکانات نسخهٔ اندروید** را بدون نیاز به اکانت توسعه‌دهندهٔ اپل یا اپ‌استور، مستقیماً روی صفحهٔ اصلی آیفون (**Add to Home Screen**) اجرا می‌کند.

---

## ۱. ویژگی‌های کلیدی معماری برای آیفون و شبکه‌های داخلی ایران

- **پوشش ۱۰۰٪ ماژول‌ها و دسترسی‌ها (`RBAC`)**: میز کار فرماندهی، داشبورد مالی بومی، اتوماسیون اداری بازطراحی‌شدهٔ توکا، دبیرخانهٔ یکپارچه (صادره/وارده/رزرو اندیکاتور)، دستورکار رایکا، فروشگاه و خزانه‌داری کایر، سامانه مودیان، دارایی‌های IT، صورتجلسات و پیام‌رسان سازمانی میها.
- **صددرصد خودکفا و بدون وابستگی به اینترنت خارجی (`Zero External CDN`)**: موتور گرافیکی `CanvasKit`، فونت فارسی `Vazirmatn` و تمام آیکن‌های متریال داخل خود بسته قرار دارند و هیچ درخواستی به `gstatic.com` یا سرورهای گوگل ارسال نمی‌شود (اجرای سریع حتی روی اینترنت ملی یا شبکهٔ داخلی سازمان).
- **تجربهٔ بومی iOS در حالت تمام‌صفحه (`Standalone`)**:
  - پوشش کامل **Notch** و **Dynamic Island** (`viewport-fit=cover` و `black-translucent`).
  - ۱۲ صفحهٔ آغازین (**Retina Splash Screen**) اختصاصی برای تمام مدل‌های آیفون (از iPhone SE تا iPhone 16 Pro Max) و آیپد.
  - جلوگیری کامل از زوم ناخواستهٔ سافاری هنگام لمس کادرهای ورود متن.
  - بنر هوشمند فارسی برای راهنمایی نصب در Safari و هشدار خودکار هنگام باز شدن لینک داخل مرورگر تلگرام/اینستاگرام/واتساپ.
- **اعلان قفل صفحهٔ آیفون (`iOS 16.4+ Web Push`)**: متصل به سرویس موجود بک‌اند (`/api/notifications/push-vapid-key` و `push-subscribe`) با پشتیبانی رسمی از سرور پوش اپل (`web.push.apple.com`) و شمارندهٔ آیکن (`App Badge`).
- **چاپ AirPrint و شیت اشتراک‌گذاری بومی iOS**: چاپ مستقیم فاکتورها، پیش‌فاکتورها، بیجک، صورت‌حساب و گزارش‌ها با پنجرهٔ بومی **AirPrint / Save as PDF** آیفون و تحویل فایل‌های PDF/Excel با **Web Share Sheet** (ذخیره در Files، ارسال به تلگرام/واتساپ، AirDrop).

## ۲. تنظیم آدرس سرور بدون نیاز به کامپایل (`pwa-config.js`)

فایل `pwa-config.js` در ریشهٔ پوشه با یک ویرایشگر متن ساده (مثل Notepad) قابل تنظیم است:

### حالت الف — میزبانی روی همان سرور اصلی بک‌اند (پیشنهادی و بدون تنظیم CORS)
اگر پوشهٔ وب‌اپ را کنار سایت اصلی خود (مثلاً در زیرپوشهٔ `https://erp.company.ir/app/`) قرار دهید، **نیازی به هیچ تغییری در `pwa-config.js` نیست**! برنامه به‌طور خودکار دامنهٔ `https://erp.company.ir` را به عنوان سرور تشخیص می‌دهد.

### حالت ب — میزبانی روی دامنه یا پورت جداگانه
کافی است فایل `pwa-config.js` را باز کرده و آدرس سرور بک‌اند را وارد کنید:
```javascript
window.FOROUGH_CONFIG = {
  apiBaseUrl: "https://erp.company.ir",
  autoSameOrigin: true,
  serverProfiles: []
};
```
> **نکتهٔ CORS در حالت ب**: اگر دامنهٔ PWA با دامنهٔ API متفاوت باشد (مثلاً `pwa.company.ir` به `api.company.ir`)، مطمئن شوید مبدأ `https://pwa.company.ir` در تنظیمات `AllowedOrigins` بک‌اند ASP.NET Core مجاز شده است.

## ۳. روش‌های استقرار روی سرور

### روش اول: ویندوز سرور و IIS (پیشنهادی برای کنار بک‌اند دات‌نت)
فایل `web.config` از پیش داخل ریشهٔ بسته قرار داده شده و تمام MIME Typeهای لازم (`.wasm`, `.mjs`, `.webmanifest`, `.ttf`, `.otf`) را تنظیم می‌کند:
1. محتویات پوشهٔ بسته را در مسیر دلخواه سرور کپی کنید، مثلاً `C:\inetpub\ForoughArya-PWA`.
2. در **IIS Manager** روی سایت اصلی خود راست‌کلیک کرده و **Add Virtual Directory** (یا **Add Application**) را بزنید:
   - **Alias**: `app` (بنابراین آدرس وب‌اپ می‌شود `https://yourdomain.com/app/`)
   - **Physical path**: `C:\inetpub\ForoughArya-PWA`
3. تگ `<base href>` در `index.html` به‌صورت پویا مسیر `/app/` را تشخیص می‌دهد و بلافاصله بدون تنظیم اضافی اجرا می‌شود!

### روش دوم: لینوکس و Docker / Docker Compose
داخل پوشهٔ `deploy/` فایل‌های آمادهٔ `Dockerfile`، `docker-compose.yml` و `nginx.conf` قرار دارند:
```bash
cd deploy
docker compose up -d --build
```
سرویس روی پورت `8085` بالا می‌آید و فایل `pwa-config.js` به‌صورت Volume متصل است تا هر زمان بدون بیلد مجدد قابل ویرایش باشد.

### روش سوم: Nginx مستقیم روی لینوکس
1. محتویات پوشهٔ اصلی را در `/var/www/forough-pwa` کپی کنید.
2. فایل `deploy/nginx.conf` را در `/etc/nginx/conf.d/forough-pwa.conf` کپی و مسیر `root` را روی `/var/www/forough-pwa` تنظیم کنید، سپس `sudo nginx -t && sudo systemctl reload nginx` را بزنید.

## ۴. راهنمای نصب روی آیفون برای کاربران سازمان

1. آدرس وب‌اپ (مثلاً `https://erp.company.ir/app/`) را در مرورگر **Safari** آیفون باز کنید.
2. در نوار پایین سافاری روی دکمهٔ **Share** (مربع با فلش رو به بالا `⎋`) بزنید.
3. از منوی بازشده گزینهٔ **Add to Home Screen** (`➕`) را انتخاب کنید.
4. در بالا سمت راست دکمهٔ **Add** را لمس کنید.
5. آیکن **«فروغ آریا»** به صفحهٔ اصلی آیفون اضافه می‌شود. با باز کردن برنامه از این آیکن:
   - برنامه کاملاً تمام‌صفحه و بدون نوار آدرس سافاری باز می‌شود.
   - برای فعال‌سازی نوتیفیکیشن قفل صفحهٔ آیفون (نیازمند **HTTPS** و **iOS 16.4+**): پس از ورود به حساب، از منوی تنظیمات میز کار گزینهٔ **«اپلیکیشن آیفون (iOS PWA) و اعلان وب»** ← **«فعال‌سازی اعلان این دستگاه»** را بزنید.
