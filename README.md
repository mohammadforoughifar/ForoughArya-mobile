# ForoughArya Mobile

Flutter client for ForoughArya business workflows.

## Included in this snapshot
- Work orders
- Authentication and API client
- Initial Office Automation module and interactive design preview

> The Automation module is under active integration. This repository preserves the current source snapshot; production endpoint verification and a clean integration build are still required.

Open `previews/automation-workspace.html` in a browser. It is offline and RTL.
